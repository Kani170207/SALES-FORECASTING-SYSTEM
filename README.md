# 📈 Sales Forecasting & Revenue Prediction System

## Overview

A Data Science and Business Intelligence project that analyzes historical Walmart sales data and predicts future sales trends using Facebook Prophet.

The application provides interactive dashboards, forecasting capabilities, historical analysis, and business insights through a Streamlit web application.

---

## Features

### Dashboard

* Total Revenue KPI
* Average Weekly Sales KPI
* Store Count
* Department Count
* Weekly Sales Trend Visualization

### Historical Analysis

* Top Performing Stores
* Top Performing Departments
* Interactive Visualizations

### Forecasting

* Sales Forecasting using Prophet
* Future Revenue Prediction
* Confidence Interval Analysis
* 26 Week Forecast Horizon

### Business Insights

* Automated Business Recommendations
* Revenue Drivers Identification
* Sales Trend Analysis
